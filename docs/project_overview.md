# 项目概览

## 目标

研究学术引用的内容合理性与网络行为，把可解释的分析结果整理成支持人工复核的证据材料。研究对象可包括具体引用、论文、作者、期刊及其关联群体，但不同层级的结论不能直接互相替代。

## 核心研究问题

1. **内容支持**：被引来源是否支持引用位置的具体主张？检索失败与真实矛盾如何区分？
2. **群体异常**：在学科、规模和时间等背景下，是否出现超额引用或异常互惠模式？
3. **主体关联**：观察到的合作、机构和发表关系是否可靠，是否对应正确时点？
4. **联合证据**：结构、语义和时间信号组合后，是否提供单一方法没有的信息？
5. **有效性与误报**：哪些正常学术行为容易被误判？跨领域和采样变化会怎样影响结果？
6. **治理可用性**：如何形成可追溯、可更正、便于独立复核的材料，而非自动定责名单？

## 分析对象和输出

| 分析单位 | 可输出内容 | 不应直接推出 |
|---|---|---|
| 引用实例 | 支持/不支持/无法判断及证据位置 | 作者的主观意图 |
| 论文引用边 | 已观测关系、权重和时间 | 每次引用提及的真实语义 |
| 期刊或作者群体 | 相对基准的结构信号 | 群体已经构成引用操纵 |
| 主体关系 | 有出处的署名、机构与发表关系 | 自动成立的利益输送 |
| 案例材料 | 证据、反例、缺口、复核记录 | 自动处罚或公开指控依据 |

## 范围和边界

主题包括引用准确性、异常自引/互引、引文堆叠、可能的强制引用及多源证据解释。不能仅从公开引文图推断付费、胁迫或组织动机；这类问题通常需要额外可靠材料。

本库是研究共享空间，不是已建成的监测平台，也不提供自动学术不端认定。阶段目标和验收条件见[路线图](roadmap.md)。
