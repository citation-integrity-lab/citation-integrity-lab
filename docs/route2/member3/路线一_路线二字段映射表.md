## 一、字段映射关系

| 路线一字段 | 路线二字段 | 映射规则 |
|-----------|-----------|----------|
| citation_id | — | 路线一判断记录主键，不直接进入边表 |
| citing_doc_id | citing / citing_short | 施引论文ID，通过短ID对齐 |
| cited_doc_id | cited / cited_short | 被引论文ID，通过短ID对齐 |
| label | — | 语义标签，不经过边表 |

| failure_status | 边表可增加一列 | 对齐失败时记录 |

## 二、对齐主键

- **节点级对齐**：citing_short / cited_short（裸 W 号）与路线一 cited_doc_id 直接对应
- **边级对齐**：edge_id 作为边的主键，路线一 citation_id 通过 citing_short + cited_short 组合映射
- **共同主键**：edge_id

## 三、缺失值处理规则

- 无法对齐时，路线二的边保留，标记 failure_status
- failure_status 取值：no_external_match / ambiguous_alignment / doi_not_found
- 空单元格表示 null，不写 0 或短横线
- 不对齐的边不进入作者/机构引文图

## 四、已冻结口径（成员1、2确认）

1. 三个 score 校准前统一填 null
2. evidence_spans 用 Unicode 码点偏移
3. label / display_name / judgment_label 分层

## 五、适用范围与本次试连限制

### 适用范围

- 路线一主数据源不改为 OpenAlex；OpenAlex 仅用于论文 ID 和引文关系对齐。
- citing_short / cited_short 使用 OpenAlex 裸 W 号，与路线一 citing_doc_id / cited_doc_id 对应。
- 原始 PMCID、DOI 仍保留在路线一主数据中，不用 W 号覆盖。
- citation_id 是路线一具体试标记录的稳定 ID；edge_key 是论文对匹配键；两者不可视为同一 ID。实际 edge_id 由路线二边表生成后再关联。
