# 快速导航

先看[项目概览](project_overview.md)，理解分析单位和结论边界，再按自己的问题进入对应目录。文件组织不预设人员职责。

## 阅读研究

从[文献库](../literature/README.md)出发，核对原文和方法；看[来源核验](source_audit.md)区分已确认信息与待核验说法。需要扩展阅读时沿用[检索协议](../literature/search_protocol.md)。

## 准备数据或方法

先看[数据目录](../data/README.md)和[方法库](../methods/README.md)。数据卡记录版本与许可，方法档案记录固定代码、环境和输入输出。登记完毕不等于运行成功。

## 开展实验或案例分析

先选[评估协议](../benchmarks/README.md)，复制[实验模板](../templates/experiment.md)。有候选案例后再整理[证据材料](../templates/case.md)，保留替代解释、缺失信息与复核意见。

## 分享新成果

按[贡献指南](../CONTRIBUTING.md)提交一次清晰的小改动。提出新问题或改变研究口径时，用[研究讨论记录](../discussions/README.md)，不需要改成某人的长期专属目录。
