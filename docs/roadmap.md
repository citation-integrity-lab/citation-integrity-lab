# 项目研究路线图

按研究成熟度推进，不按人员或日历排任务。每阶段通过验收后再扩大范围；可以并行准备文献和数据，但不能跨过证据门槛升级结论。

| 阶段 | 研究目标 | 可检查的成果 | 进入下一阶段的条件 |
|---|---|---|---|
| 1. 问题与资料 | 明确分析对象、标签和相关研究 | 文献目录、检索日志、术语与边界 | 核心来源可追溯，待核验项明确 |
| 2. 数据与接口 | 建立可复用的小规模数据基础 | 数据卡、Schema、采样与标注规范 | 版本、许可、缺失和实体对齐可核查 |
| 3. 独立基线 | 跑通语义、网络和图谱基本流程 | 固定环境、命令、日志和失败分析 | 他人可按记录运行，不要求必须检出异常 |
| 4. 联合证据 | 比较独立方法与证据组合 | 融合规则、消融、正常对照和案例 | 指标口径一致，增量价值与局限明确 |
| 5. 稳健评估 | 检查领域、时间和采样变化 | 跨域测试、敏感性分析、不确定性 | 结果可重复，误报与失效条件可解释 |
| 6. 复核与共享 | 形成可使用、可更正的研究产出 | 脱敏案例、复核协议、技术报告 | 来源与权限审查完成，结论不过界 |

## 近期最小研究闭环

选择一个有来源记录的小样本 → 分别运行适用方法 → 整理一个可复查案例或空结果 → 请另一位研究者检查解释和运行记录。

这是项目层面的最小验证路径，不绑定特定执行人。高级图模型、大规模采集与自动评分是否开展，取决于前序证据、数据质量和资源条件。
