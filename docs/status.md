# 项目状态

资料更新：2026-08-31。此表按研究内容记录成熟度，不记录个人完成率。

| 项目内容 | 当前可用 | 尚未验证 |
|---|---|---|
| 研究框架 | 项目问题、技术路线、阶段目标 | 方法组合的实际有效性 |
| 文献调研 | 专题摘要、核心入口、待核验清单 | 完整系统综述与所有性能数据 |
| 数据基础 | 候选来源、Schema、标注原则和模板 | 统一数据快照、自动采集与实体对齐 |
| 方法复现 | 六类方法档案；两项官方代码固定版本 | 安装、运行、原论文指标复现 |
| 实验评估 | 评估协议、实验和对照模板 | 真实运行日志、对比表与消融结果 |
| 案例与治理 | 案例模板、证据要求和复核流程 | 经独立复核的真实案例 |
| 仓库协作 | 导航、贡献规范、Issue/PR模板、检查脚本与CI配置 | 成员权限与主分支强制保护需看平台实际设置 |

## 文献与复现状态分开记录

文献：待核验 → 已核对来源 → 已精读 → 已交叉复核。

方法：

- `planned`：方案与输入输出已登记。
- `source_pinned`：官方来源、commit 和仓库声明的许可已登记，尚未运行。
- `example_runs`：特定示例运行成功，有日志。
- `evaluated`：按声明的协议完成评估，有真实结果。
- `independently_verified`：由另一位研究者独立复核。

[方法登记表](../methods/catalog.json)是机器可检查的状态记录。升级到运行或评估阶段必须链接实验记录；失败、空结果和未发现候选群体均应如实记录。
