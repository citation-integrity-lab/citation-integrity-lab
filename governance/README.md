# 证据解释与治理研究

本目录研究如何把检测输出整理成可核查材料，不提供自动学术不端认定或替代机构调查的结论。

## 三个层次分开

1. **观察事实**：哪些引用、文字和关系确实有来源记录？
2. **分析推断**：什么模型或比较基准给出什么信号，有哪些误差与替代解释？
3. **复核结论**：查阅原始证据后，哪些解释被支持，哪些仍无法判断？

不要把模型分数直接写成事实，也不要从公开网络关系推断付款、胁迫或主观合谋。

## 最小证据清单

数据版本与采样范围、原文或记录定位、分析方法与参数、实体消歧与时点、缺失信息、正常解释、复核意见与更正历史。使用[案例模板](../templates/case.md)记录。

## 建议复核流程

候选信号 → 检查数据与实体 → 查原文和关系出处 → 寻找反例与正常解释 → 独立复核 → 记录支持程度与未解决问题。

工作流状态可以是“待查原文、数据不足、待独立复核、已记录解释、暂无法判断”，不预设五级或六级风险，也不把等级数量当成科学有效性的证据。

## 共享和更正

真实身份映射、非公开审稿材料及敏感指控不进一般共享结果。对外使用需要重新核对访问范围、文字引述授权与结论措辞。保留更正和撤回路径；未经明确授权不联系当事人、举报或公开名单。

治理文献的候选入口包括 COPE 的[引用操纵讨论文件](https://publicationethics.org/files/COPE_DD_A4_Citation_Manipulation_Jul19_SCREEN_AW2.pdf)。该文件是讨论资源，本库尚未完成逐条精读；本页流程为项目设计，不宣称已满足某司法辖区法规或正式调查标准。
