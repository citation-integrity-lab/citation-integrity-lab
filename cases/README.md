# 案例与人工复核

当前没有由本项目检测并完成复核的案例。此目录不展示真实主体的风险名单。

复制[案例模板](../templates/case.md)，围绕一个案例整理：
观察到的引用结构、相关语义证据、主体关系来源、可能的正常解释、数据缺口和下一步核查。

## 共享范围

组内主仓库优先保存脱敏案例摘要。真实主体映射、非公开审稿材料和涉及声誉的指控只进入有明确权限的材料库。
需要对外共享时重新检查内容，不以“仓库曾经私有”作为可以公开的依据。

## 结论口径

使用“待复核的结构信号”“证据不足”“可由正常合作解释”等与证据相符的措辞。
复核状态可以是：待看原文、证据缺失、待二人复核、已记录解释、暂无法判断。这些是工作流状态，不是学术不端风险等级。

不设没有依据的0—100分，也不自动定责、联络被研究主体或举报。
