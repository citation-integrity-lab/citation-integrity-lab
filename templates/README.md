# 共享成果模板

按实际产物选一份填写，不需要每次全部提交。

| 产物 | 模板 | 归档位置 |
|---|---|---|
| 文献精读 | [文献卡片](literature_note.md) | literature/专题/ |
| 数据快照或数据集 | [数据卡](dataset.md) | data/对应数据目录/ |
| 方法原理与复现档案 | [方法档案](method.md) | methods/方法/ |
| 单次运行与评估 | [实验记录](experiment.md) | experiments/方法或问题/ |
| 案例证据与解释 | [案例记录](case.md) | cases/案例ID/ |
| 问题、决策与阶段总结 | [研究进展](progress.md) | discussions/ |

填写贡献者便于溯源，但不要按人建立互不相通的研究目录。“待填”只表示未知，不是已经存在的结果。
