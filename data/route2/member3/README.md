## 二、按周工作记录

### 第1周（08-24 至 08-30）：文献调研与路线设计
完成引文卡特尔、CIDRE、Ego-Network等代表性方法的调研和比较。明确路线二基本思路：先利用网络结构和异常互引指标发现可疑群体，再通过局部网络分析判断群体内部是否存在异常引用。综合可复现性、公开代码和已有验证效果，确定将CIDRE作为路线二的核心baseline。与成员4的分工明确：成员3负责找异常圈子，成员4负责解释圈子里的关系。本周暂无数据文件产出。

### 第2周（08-31 至 09-06）：跑通CIDRE + Ego-Network案例
完成CIDRE环境搭建，用OpenAlex API取200篇论文数据。构建引文网络，跑通简化版异常检测，得到Top1候选W4308616064。用NetworkX的ego_graph()画了2跳Ego-Network图。本周产出：初步边表数据、Ego-Network图、CIDRE运行说明。

### 第3周（09-07 至 09-13）：修正Ego-Network + 自引用影响分析
把ego_graph()改成手动双向扩展（predecessors+successors），保证入边和出边都被包含。去除自引用后重新计算，Top1从W4308616064（1.79）变为W4402754006（1.02）。本周产出：修正后的2跳Ego图、去除自引用前后对比结果。

### 第4周（09-14 至 09-20）：数据质量清洗 + V2评分迭代
增加年份倒挂、自引用、重复边三项预检：发现10条倒挂、10条自引用、0条重复。剔除倒挂边后，网络从130条边降到120条边，节点保持200。V2评分：入度改为全局最大入度归一化，权重调整为入度2.0、互惠2.0、内部密度0.5。本周产出：清洗后边表、V2指标说明、V2 Top10候选表。

### 第5周（09-21 至 09-27）：基线冻结 + 字段映射初版

## 三、使用说明
1. 正式基线为 route2_baseline_v1（116条边、104个有效节点），不再通过实时API覆盖。
2. 网络指标以 final_top_candidates_v2.csv 为准，未列入候选表的节点 score_v2 为 pending。
3. 扩网v1（36,734节点/43,158边）为固定快照；normal_edges/normal_nodes 为静态快照，入边随OpenAlex更新会缓慢变化，实验统一用快照。
4. 对照分组以"任务1_对照样本_稳定总名单_49条_group修正r1.csv"为准，44/5子表未重新抽样；5条盲测为正常对照留出集，与撤稿案例盲测名单区分。
5. 证据三档（公开已证实/公开指控/算法候选）不合并计数；算法候选不等于已证实引文不端。
6. 所有文件哈希见 route2_baseline_v1说明.md；脚本使用OpenAlex API时请通过环境变量 OPENALEX_API_KEY 提供密钥，勿硬编码。
