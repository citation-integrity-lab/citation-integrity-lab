# 5共同样本网络特征表 运行说明

## 环境
- Python 3.7
- networkx >= 2.0
- pandas >= 1.1.0（本脚本未使用，但仓库其他脚本用到）
- openpyxl（pandas 读 xlsx 需要）

## 输入文件
- `final_edges_no_selfcite.csv`（116条边基线，batch=route2_baseline_v1_116edges）
- `final_top_candidates_v2.csv`（V2 Top10候选表）

## 计算步骤
1. 读边表，用 networkx 建有向图 G（节点=citing_short/cited_short，边=引用关系）
2. 读 V2 候选表，存 node_id → score_v2
3. 对5条共同样本逐条计算：
   - indegree/outdegree：G.in_degree/out_degree(u, weight='weight')
   - reciprocity：出邻居中存在反向边的比例，分母为出度；出度为0时记 null
   - internal_density：出邻居之间连边数 ÷ C(出度,2)；出度≤1时分母为0，记 null
   - ego_2hop_nodes/edges：nx.ego_graph(G, u, radius=2) 的节点数/边数
   - score_v2：从候选表取，取不到记 pending
4. 输出 `5共同样本网络特征表.csv`

## 版本号
route2_baseline_v1_116edges（对应116条边基线）

## 缺失值口径

- **internal_density**：出度≤1时，分母 C(出度,2)=0，无法计算，记 null，不记 0.0。
- **reciprocity**：出度=0时，分母为 0，记 null；出度≥1时正常计算。
- **score_v2**：施引方不在 V2 Top10 候选表时，记 pending，不自行套公式。
- 其余字段（indegree、outdegree、ego_2hop_nodes、ego_2hop_edges）均可直接计算，不涉及 null。
