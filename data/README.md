# 数据资源与共享规范

研究数据分为引用语义数据、书目与引文元数据、主体关联、案例证据四类。来源可访问不等于内容完整或可任意再分发。

| 资源 | 候选用途 | 使用前核查 | 入口 |
|---|---|---|---|
| Sarol Citation-Integrity | 引用上下文、证据、标签 | 固定版本、官方拆分、许可和全文边界 | [作者仓库](https://github.com/ScienceNLP-Lab/Citation-Integrity) |
| SciCiteVal | 外部引用核验评估 | 样本构造、源ID泄漏、版本和许可 | [作者数据卡](https://huggingface.co/datasets/birdie0111/SciCiteVal) |
| OpenAlex | 书目、引文与实体关联候选 | 当前字段、访问条件、覆盖与缺失 | [官方帮助中心](https://help.openalex.org/) |
| DBLP及其他书目来源 | 书目与实体对齐候选 | 不同产品/版本是否含需要的引用和全文 | [官方入口](https://dblp.org/) |
| 原文及案例佐证 | 引用核验和关系确认 | 访问授权、出处、时点、保密与使用范围 | 逐案例登记，不整包公开 |

此表是数据来源目录，不表示已取得这些数据的统一快照。

## 数据进入项目的顺序

来源与许可核查 → 固定版本或快照 → 数据卡 → 采样清洗与实体对齐 → 质量检查 → 方法适配。
共享字段见[Schema](schema.md)，语义标签见[标注原则](annotation.md)。

每份数据使用[数据卡模板](../templates/dataset.md)，记录哈希、时间范围、采样、过滤、缺失、访问权限和已知偏差。不同来源的同名实体不能直接合并。

## 存储边界

仓库内保存元数据规范、小型脱敏示例和获取说明。大型数据、受限全文、身份映射与非公开材料进入有访问控制的存储；链接也不能含临时访问凭证。

不要把模型权重、API密钥或付费数据库批量导出提交到Git。`.gitignore`仅降低误提交概率，不是安全边界。
