# 学术知识图谱与联合证据研究

图谱用于组织有出处的实体关系，证据融合用于比较不同信号是否提供互补信息。两者都需要保留不确定性。

## 图谱研究的最小问题

论文由谁署名、发表于哪里、引用哪些论文、作者在相关时点与哪些机构关联？消歧错误和历史机构错配会影响后续解释。

[图谱方法](../../methods/knowledge_graph/README.md)采用四类实体与四类基础关系。复杂关系和图表示模型应由具体研究问题驱动，不以模型数量作为完成度。

## Gupta 等，2026预印本

Trust-Aware Citation Cartel Ranking in Scholarly Knowledge Graphs 把引用意图与网络结构用于论文社区排序。[预印本](https://arxiv.org/abs/2607.06528)

当前作为联合分析的研究参考，不承诺完整官方数据或运行工件可获取。原材料中的具体性能和鲁棒性数字尚未逐项核验，不进入正式对照结论。

## 后续实验问题

语义证据是否补充结构分析？去掉某类信号后排序怎样变化？正常合作群体会不会同样得高分？这些问题通过[融合方法](../../methods/evidence_fusion/README.md)和[评估协议](../../benchmarks/README.md)落实。
