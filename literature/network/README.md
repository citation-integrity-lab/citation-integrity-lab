# 引文网络与异常群体研究

网络分析的目标是寻找需要进一步解释的模式；正常学术共同体本来就可能密集互引。

| 方法 | 适用问题 | 解释边界 |
|---|---|---|
| CIDRE | 相对统计基准的期刊群体异常 | 不直接判断单个引用的语义和研究者意图 |
| Ego-Network | 种子附近有哪些有向关系 | 局部邻居不是自动成立的异常群体 |
| Leiden / Louvain | 如何划分网络社区 | 社区质量不等于不端检测准确率 |
| SCC | 哪些节点通过有向路径相互可达 | 不等于任意两节点都有直接互引 |

[CIDRE原论文](https://www.nature.com/articles/s41598-021-93572-3)使用考虑期刊规模和社区结构的零模型，并通过 donor/recipient 角色刻画群体。细节和上游来源见[方法档案](../../methods/cidre/README.md)。

Fister 2016与Davis报告提供相关线索；具体原文核验状态见[来源页](../../docs/source_audit.md)。不把报告中的所有描述当作已确认结论。

研究时保留学科、时间、节点粒度、自环与边权定义，检查采样边界对期望引用的影响。群体发现与局部解释分别记录。
