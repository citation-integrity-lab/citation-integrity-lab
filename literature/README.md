# 文献与调研库

按研究问题组织文献，并保留检索方法和不确定信息。一个研究可以关联多个专题，不必复制多份摘要。

| 专题 | 关注问题 | 入口 |
|---|---|---|
| 引用语义 | 主张、证据和引用准确性 | [语义研究](semantic/README.md) |
| 数据与标注 | 数据来源、标签、跨领域评估 | [数据研究](datasets/README.md) |
| 引文网络 | 超额引用、群体结构和局部解释 | [网络研究](network/README.md) |
| 图谱与证据融合 | 主体关系、语义结构联合分析 | [图谱研究](knowledge_graph/README.md) |
| 治理研究 | 引用操纵讨论、人工复核与研究边界 | [治理入口](../governance/README.md) |
