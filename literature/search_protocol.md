# 可共享的检索与精读方法

## 明确范围

每次调研先写研究问题、分析单位（引用实例/论文/作者/期刊/社区）、领域、时间范围和语言。注明这是定向检索还是系统综述，不对未覆盖部分声称“全面”。

## 可复用检索词

以下是起始查询建议，并非已执行的完整检索记录。

| 问题 | 英文关键词组合 |
|---|---|
| 引用支持与错误 | citation integrity; citation verification; quotation errors; citation entailment |
| 网络异常 | citation cartel; citation manipulation; citation stacking; anomalous citation groups |
| 主体关系 | scholarly knowledge graph; author disambiguation; citation network anomaly |
| 联合证据 | citation intent + graph; trust-aware citation ranking; semantic citation weighting |
| 治理 | citation manipulation + publication ethics; coercive citation; editorial policy |

优先查出版商、ACL Anthology、正式会议/期刊、arXiv 作者原文、官方代码与数据卡。搜索结果摘要只用于定位，不作为性能结论的唯一依据。

## 纳入和排除

纳入与问题直接相关且来源可追溯的工作；明确区分同行评审文章、预印本、报告和博客。
记录排除原因，例如只讨论推荐系统而不验证引用、无可核对全文、方法与分析单位不匹配。题名重复或版本重复需要合并关联。

## 每次留下什么

检索日期、平台、原始查询、筛选条件、记录数量、去重与纳入排除规则、论文列表，以及补充的前向/后向引用检索。复制[文献模板](../templates/literature_note.md)做精读。

精读抓住：问题 → 数据 → 方法 → 输出 → 评价 → 局限 → 项目可复用点。性能数字必须带原文表号、数据拆分和实验设置。错误或存疑引用进入[待核验清单](../docs/source_audit.md)，不默默改成已确认来源。
