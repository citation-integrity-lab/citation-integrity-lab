# 数据集与跨领域评估研究

| 数据 | 研究用途 | 边界 |
|---|---|---|
| Sarol 2024 | 生物医学引用证据与准确性核验 | 保留官方被引论文划分，不能推广为所有学科 |
| SciCiteVal | 引用上下文与证据的三类核验 | 人工改写错误样本不能代表自然错误发生率 |

## SciCiteVal

[LREC 2026论文](https://aclanthology.org/2026.lrec-1.125/)报告1,034条样本：Correct 302、Incorrect 302、Unrelated 430。

[作者数据卡](https://huggingface.co/datasets/birdie0111/SciCiteVal)说明错误样本由标注者改写 QASA 内容构造，并保留可追溯的源ID；数据卡声明 CC BY 4.0。

## 共享的比较方法

比较输入单位、证据范围、标签定义、自然/构造样本、领域、拆分和许可。不能只比较样本量或一个准确率。

同源样本和改写版本的泄漏要单独检查。外部测试集不能同时用于选择提示词和参数。方法分数不能直接解释为现实不端概率。

数据登记规则见[数据目录](../../data/README.md)，测试设计见[评估协议](../../benchmarks/README.md)。
