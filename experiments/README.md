# 实验记录

当前没有已核验的组内实验结果。

完成一次运行后，把[实验模板](../templates/experiment.md)复制为对应方法目录下的日期文件，例如 `experiments/cidre/2026-09-04-pilot.md`。该路径只是命名示例，不表示实验已完成或已安排在该日。

保留输入版本、配置、固定代码 commit、运行命令、机器环境、输出和错误。结果表里写本次实际数值；没有计算就写“未计算”，不要填0。

每次运行区分：合成演示、真实小样本、基准复现、跨领域测试。没有金标准时不报告准确率、召回率或不端检出率。

失败记录也有共享价值，应写明失败发生在哪里、已尝试什么、下一步最小操作。
