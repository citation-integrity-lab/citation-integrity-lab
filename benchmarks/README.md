# 实验评估协议

状态：项目协议草案，尚无本项目的真实评估结果。正式实验先固定问题、数据、比较对象和指标，再运行。

## 按任务选择指标

| 任务 | 可评估内容 | 注意事项 |
|---|---|---|
| 证据检索 | Recall@k、证据覆盖与检索失败率 | 需要明确金标准证据；k与文本单位固定 |
| 引用判别 | macro/micro-F1、逐类P/R、混淆矩阵 | 标签映射、未知类和无法判断样本的分母明确 |
| 群体异常 | 有标签时的P/R；人工复核的Precision@k | 没有完整标签就不能报告整体召回或真实发生率 |
| 图谱质量 | 实体对齐抽检、关系准确性、时点一致性 | 记录抽样规则、人工证据和覆盖率 |
| 候选排序 | 排名质量、稳定性、复核成本 | 排名稳定不等于不端识别正确 |
| 概率输出 | 校准与覆盖率、选择性预测风险 | 未校准分数不称为可信概率 |

## 数据划分与泄漏

保留官方划分；新增实验明确分组单位。防止同一被引文献、同源改写、作者群体或时间信息在不适当条件下跨集合泄漏。
若采用时间评估，明确哪些数据在预测时可见，不能用未来关系构造当时的特征。
外部测试集不参与模型、提示词、阈值和权重选择。

## 对照与消融

在同一数据版本、分析单位与资源条件下比较。至少考虑适用的简单基线，以及正常合作/相近学科/相近规模等匹配对照。
联合方法分别移除语义、结构、关系或时间证据；记录缺失证据比例。没有标签的社区检测不伪装成分类准确率。

## 稳健性和不确定性

检查随机种子、阈值、领域、时间窗口、网络采样边界和数据缺失的敏感性。
适用时报告多次运行或置信区间；相关样本按论文或群体等合适单位重采样，避免把高度相关引用当成独立观测。

## 结果最低记录

`run_id`、代码/模型版本、环境、数据哈希、采样/划分、配置、随机种子、原始输出、指标定义、失败样本、资源成本与局限。
一份结果不满足可比条件时，单独描述，不强行加入排行榜。
