# 社区、连通与结构对照

状态：`planned`。此页规定实验时要记录的内容，不提供已运行实现。

| 工具 | 用途 | 需要写清 |
|---|---|---|
| Louvain / Leiden | 社区划分与结构对照 | 图方向与投影、边权、目标函数、分辨率、种子、库版本 |
| SCC | 有向路径的强连通结构 | 方向、节点粒度、自环处理和分析范围 |
| 密度/互惠率 | 描述群体结构 | 分母、加权或二值、是否排除自环、图边界 |

SCC不是“任意两点直接互引”。社区划分不提供不端标签，单独的密度与互惠率也没有自动定责含义。

可与[CIDRE](../cidre/README.md)比较结构发现结果，但原方法、替代实现和简化版本必须分开命名。不得把不同粒度、不同数据边界上的指标直接并排排名。
