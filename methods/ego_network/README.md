# Ego-Network：局部关系解释

状态：`planned`。用于解释种子周围的关系，不单独判定异常。

## 输入和输出约定

输入：种子ID、节点类型、数据版本、跳数、扩展方向（入边/出边/双向）、截断上限。
输出：节点表、边表、图和统计说明。

若为了选邻居使用无向遍历，输出图仍保留原始引用方向。记录自环、重复边、聚合规则和边权定义；标注被截断的节点/边数量。

## 如何评估

在可人工核对的小图上检查邻居与方向是否正确，再考察真实图中的可解释性。需要社区或SCC分析时，使用[结构方法档案](../community/README.md)的独立口径。

局部图仅显示给定采样范围，不足以自动推断全局异常、关系缺失或操纵动机。
