# 多源证据融合

状态：`planned`。目标是研究证据互补性，不预设某组权重一定有效。

## 先统一分析单位

引用实例输出可聚合到论文对，论文对可映射到群体，但每一步都要记录规则、分母和缺失情况。语义分数、网络统计显著性和来源可信度不是同一种概率。

## 候选证据

- 语义：支持判断、证据覆盖、无法判断比例。
- 网络：明确基准下的超额关系、互惠结构与社区统计。
- 主体：有时点和出处的署名、机构及发表关系。
- 时间：在数据允许时考察变化和集中现象，不用发表时间冒充已观测引用行为时间。

先生成并列证据表，再研究排序规则。未经校准不设置自动风险等级或把总分称为不端概率。

## 验证路径

对比语义单独、结构单独、联合规则和适当随机对照；逐项消融；检查不同领域、规模和采样边界的影响。只在训练/开发数据上选择权重与阈值，预留独立评估。

方法参考见[图谱与联合证据研究](../../literature/knowledge_graph/README.md)。输出通过[治理与复核协议](../../governance/README.md)解释。
